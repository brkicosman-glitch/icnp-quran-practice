# ICNP Maktab — Qur'an Practice (First 2 Juz)

This is a static GitHub Pages project focused on correct recitation practice.

## Included
- Juz 1: pages 1–22
- Juz 2: pages 22–42
- Large Uthmani Arabic text
- Page navigation
- Ayah-by-ayah listening
- Repeat an ayah 3 times
- No English translation
- Tanzil attribution

## Important
The Qur'an text is loaded from a public JSON service that uses Tanzil Uthmani 1.1 Arabic text. The app does not alter the Arabic text.

Sources:
- Tanzil Project: https://tanzil.net/
- Metadata / page structure: Tanzil Quran metadata
- Audio: EveryAyah recitation service

For a production ICNP deployment, we can later bundle a verified local copy of the exact Tanzil text and the exact reciter/audio files rather than relying on live external requests.
